LinkLedger settings

 

Sites

Manage the list of sites offered on a device's Site field. Renaming a site here updates every device already set to it; deleting one just stops offering it for new picks — devices already set to a deleted site keep that value (the Reports tab flags it as no longer in this list, if you want to clean it up).

Device roles

Choose which roles show up in the Add/Edit device Role dropdown. The roles themselves aren't customizable -- some drive real behavior (path finding, VLAN/PoE options) -- but you can hide ones you'll never use. Unchecking one here doesn't touch any device that already has it set.

Interface speeds

Choose which speeds show up in the port speed picker. Unchecking one here doesn't touch any port that already has it set — it just stops being offered for new picks.

Backup

Downloads a single .zip with everything in it — devices, ports, cables, your Sites list, and your Device roles / Interface speeds picker settings — plus a small file noting when the backup was made and which LinkLedger version made it.

Restore

Upload a backup .zip to replace your data with what's in it. Works with a full backup or one trimmed down to just the file(s) you changed (e.g. only ports.csv) — anything not included is left alone. This can't be undone, so download a fresh backup first if you want to keep what's currently there.

Change your password

Changes the password for the admin account (the one you're signed in as). You'll stay signed in on this device; other signed-in devices/browsers will need to sign in again.

Viewer account password

Sets the password for the read-only viewer account. You don't need to know its current password — this replaces it outright and signs the viewer account out everywhere.

Clear all connections

Permanently disconnects every cable and wireless/virtual link, leaving your devices and ports themselves in place — handy when you're physically re-cabling a large part of your network and would rather start the connections from a clean slate than delete them one at a time. Patch-panel front/rear pairing and LAG groupings aren't affected. This cannot be undone; download a backup first if there's any chance you'll want the connections back.

Reset all data

Permanently deletes every device, port, and cable, and also clears your Sites list and resets Device roles / Interface speeds back to their full default (everything enabled) — a genuinely blank slate to start documenting a different environment from scratch. This cannot be undone; download a backup first if there's any chance you'll want any of it back.
